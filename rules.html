Rules System¶

SQLTidy uses a rule-based system to format and rewrite SQL code. Rules are organized into two main categories: Tidy Rules and Rewrite Rules.

Rule Architecture¶

Base Rule Classes¶

All rules inherit from base classes that define the rule interface.

class sqltidy.rules.base.BaseRule[source]¶

Bases: object

Base class for all SQL formatting rules.

Rules can be either ‘tidy’ (formatting without structural changes) or ‘rewrite’ (transformations that change SQL structure).

Dialect Support:

  • Set supported_dialects to None (default) to support all dialects

  • Set to a set/list of dialect names to restrict rule to specific dialects

  • Override is_applicable() for complex dialect compatibility logic

Uppercase Keywords¶

class sqltidy.rules.tidy.uppercase_keywords.UppercaseKeywordsRule[source]¶

Bases: BaseRule

Convert SQL keywords to uppercase or lowercase based on dialect conventions.

Dialect Defaults:

  • SQL Server: UPPERCASE (T-SQL convention)

  • Oracle: UPPERCASE (PL/SQL convention)

  • PostgreSQL: lowercase (community convention)

  • MySQL: lowercase (community convention)

  • SQLite: lowercase (community convention)

Configuration:

  • Set uppercase_keywords=True to force uppercase

  • Set uppercase_keywords=False to force lowercase

  • Set uppercase_keywords=None (or omit) to use dialect default

rule_type: str | None = 'tidy'¶
order: int = 10¶

Quote Identifiers¶

Quote Identifiers Rule - Add quotes around identifiers based on dialect conventions.

This rule demonstrates dialect-specific behavior where different databases use different quoting characters for identifiers.

class sqltidy.rules.tidy.quote_identifiers.QuoteIdentifiersRule[source]¶

Bases: BaseRule

Add or normalize quotes around SQL identifiers based on dialect.

Quoting Styles by Dialect:

  • SQL Server: [identifier] or “identifier”

  • Oracle: “identifier”

  • PostgreSQL: “identifier”

  • MySQL: identifier

  • SQLite: “identifier”, identifier, or [identifier]

This rule is disabled by default. Enable via config.quote_identifiers = True.

Creating Custom Rules¶

You can create custom rules by inheriting from BaseRule:

from sqltidy.rules.base import BaseRule
from sqltidy.tokenizer import Token
from typing import List

class MyCustomRule(BaseRule):
    """Custom rule that modifies tokens."""

    def apply(self, tokens: List[Token]) -> List[Token]:
        # Implement your rule logic here
        return tokens

# Register the rule
from sqltidy import register_plugin
register_plugin(MyCustomRule())

For more details, see:

  • ../CUSTOM_RULES

  • ../CUSTOM_RULES_QUICKSTART

Configuration¶

Rules can be enabled or disabled via configuration:

from sqltidy import format_sql
from sqltidy.config import SQLTidyConfig, SQLTidyConfig

config = SQLTidyConfig(
    uppercase_keywords=True,
    leading_commas=True,
    rewrite=SQLTidyConfig(
        enable_subquery_to_cte=True
    )
)

formatted = format_sql(sql, config=config)
