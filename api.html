Plugins¶

Plugin management system for runtime rule registration.

Plugin system for SQLTidy.

Provides a decorator-based plugin registration system similar to Polars, allowing users to easily extend SQLTidy with custom formatting rules.

Example

# my_plugin.py from sqltidy.plugins import sqltidy_plugin

@sqltidy_plugin(rule_type=”tidy”, order=50) def remove_semicolons(tokens, ctx):

‘’’Remove trailing semicolons.’’’ if tokens and tokens[-1] == ‘;’:

return tokens[:-1]

return tokens

# Use from CLI: # sqltidy format input.sql –plugin my_plugin.py

# Or from Python: # from sqltidy.plugins import load_plugins # load_plugins(‘my_plugin.py’)

sqltidy.plugins.sqltidy_plugin(rule_type='tidy', order=50, supported_dialects=None, name=None)[source]¶

Decorator to register a function as a SQLTidy plugin rule.

This decorator allows you to turn any function into a formatting rule without having to create a class or understand the internals.

Parameters:

  • rule_type (str) – “tidy” (formatting) or “rewrite” (transformation)

  • order (int) – Execution order (lower runs first)

  • supported_dialects (Set[str] | None) – Set of dialects this rule applies to, or None for all

  • name (str | None) – Optional custom name for the rule class

Returns:

Decorator function

Example

@sqltidy_plugin(rule_type=”tidy”, order=100) def my_rule(tokens, ctx):

‘’’Remove trailing semicolons.’’’ if tokens and tokens[-1] == ‘;’:

return tokens[:-1]

return tokens

The decorated function should have signature:

def rule_func(tokens: List[str], ctx: FormatterContext) -> List[str]

sqltidy.plugins.register_rule_class(rule_class)[source]¶

Register a rule class directly.

Use this if you prefer to define classes rather than functions.

Parameters:

rule_class (type) – A BaseRule subclass

Example

from sqltidy.plugins import register_rule_class

class MyRule(BaseRule):

rule_type = “tidy” order = 50

def apply(self, tokens, ctx):

return tokens

register_rule_class(MyRule)

sqltidy.plugins.load_plugin_file(filepath)[source]¶

Load plugins from a Python file.

The file should contain functions decorated with @sqltidy_plugin or classes registered with register_rule_class().

Parameters:

filepath (str | Path) – Path to Python file containing plugins

Returns:

List of rule classes that were loaded

Raises:

  • FileNotFoundError – If file doesn’t exist

  • ImportError – If file can’t be imported

Return type:

List[type]

Example

from sqltidy.plugins import load_plugin_file

# Load plugins from file rules = load_plugin_file(‘my_plugins.py’)

# Add to formatter formatter.rules.extend([r() for r in rules])

sqltidy.plugins.create_plugin_formatter(config=None, plugin_files=None, plugin_dirs=None, plugin_modules=None)[source]¶

Create a SQLFormatter with plugins loaded.

Convenience function that creates a formatter and loads all specified plugins.

Parameters:

  • config – TidyConfig or RewriteConfig

  • plugin_files (List[str | Path] | None) – List of plugin file paths to load

  • plugin_dirs (List[str | Path] | None) – List of plugin directories to load

  • plugin_modules (List[str] | None) – List of module names to import

Returns:

SQLFormatter with plugins loaded

Example

from sqltidy.plugins import create_plugin_formatter from sqltidy.config import TidyConfig

formatter = create_plugin_formatter(

config=TidyConfig(dialect=’postgresql’), plugin_files=[‘my_rules.py’], plugin_dirs=[‘~/.sqltidy/plugins’]

)

result = formatter.format(sql)
