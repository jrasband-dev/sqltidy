Get a dialect by name.

Returns:

The requested SQLDialect instance.

Raises:

ValueError – If the dialect is not found.

Return type:

SQLDialect

Examples

>>> dialect = get_dialect('sqlserver')

sqltidy.dialects.registry.register_dialect(dialect)[source]¶

Register a custom dialect.

This allows users to add support for additional SQL dialects beyond the built-in ones.

Parameters:

dialect (SQLDialect) – An instance of SQLDialect to register.

Raises:

ValueError – If a dialect with the same name is already registered.

Examples

>>> class CustomDialect(SQLDialect):
...     @property
...     def name(self):
...         return 'custom'
...     # ... implement other methods
>>> register_dialect(CustomDialect())
