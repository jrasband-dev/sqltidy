sqltidy.plugins¶

Rule plugin system for SQLTidy.

Provides a decorator-based rule registration system similar to Polars, allowing users to easily extend SQLTidy with custom formatting rules.

Example

# my_rule.py from sqltidy.rules import sqltidy_rule

@sqltidy_rule(rule_type=”tidy”, order=50) def remove_semicolons(tokens, ctx):

‘’’Remove trailing semicolons.’’’ if tokens and tokens[-1] == ‘;’:

return tokens[:-1]

return tokens

# Use from CLI: # sqltidy format input.sql –rule my_rule.py

# Or from Python: # from sqltidy.rules import load_rules # load_rules(‘my_rule.py’)

sqltidy.plugins.sqltidy_rule(rule_type='tidy', order=50, supported_dialects=None, name=None)[source]¶

Decorator to register a function as a SQLTidy rule.

This decorator allows you to turn any function into a formatting rule without having to create a class or understand the internals.

Parameters:

  • rule_type (str) – “tidy” (formatting) or “rewrite” (transformation)

  • order (int) – Execution order (lower runs first)

  • supported_dialects (Set[str] | None) – Set of dialects this rule applies to, or None for all

  • name (str | None) – Optional custom name for the rule class

Returns:

Decorator function

Example

@sqltidy_rule(rule_type=”tidy”, order=100) def my_rule(tokens, ctx):

‘’’Remove trailing semicolons.’’’ if tokens and tokens[-1] == ‘;’:

return tokens[:-1]

return tokens

The decorated function should have signature:

def rule_func(tokens: List[str], ctx: FormatterContext) -> List[str]

sqltidy.plugins.register_rule_class(rule_class)[source]¶

Register a rule class directly.

Use this if you prefer to define classes rather than functions.

Parameters:

rule_class (type) – A BaseRule subclass

Example

from sqltidy.rules import register_rule_class

class MyRule(BaseRule):

rule_type = “tidy” order = 50

def apply(self, tokens, ctx):

return tokens

register_rule_class(MyRule)

sqltidy.plugins.load_rule_file(filepath)[source]¶

Load rules from a Python file.

The file should contain functions decorated with @sqltidy_rule or classes registered with register_rule_class().

Parameters:

filepath (str | Path) – Path to Python file containing rules

Returns:

List of rule classes that were loaded

Raises:

  • FileNotFoundError – If file doesn’t exist

  • ImportError – If file can’t be imported

Return type:

List[type]

Example

from sqltidy.rules import load_rule_file

# Load rules from file rules = load_rule_file(‘my_rules.py’)

# Add to formatter formatter.rules.extend([r() for r in rules])

sqltidy.plugins.load_rules_from_directory(directory)[source]¶

Load all rule files from a directory.

sqltidy.plugins.create_rule_formatter(config=None, rule_files=None, rule_dirs=None, rule_modules=None)[source]¶

Create a SQLFormatter with rules loaded.

Convenience function that creates a formatter and loads all specified rules.

Parameters:

  • config – SQLTidyConfig

  • rule_files (List[str | Path] | None) – List of rule file paths to load

  • rule_dirs (List[str | Path] | None) – List of rule directories to load

  • rule_modules (List[str] | None) – List of module names to import

Returns:

SQLFormatter with rules loaded

Example

from sqltidy.rules import create_rule_formatter from sqltidy.rulebook import SQLTidyConfig

formatter = create_rule_formatter(

config=SQLTidyConfig(dialect=’postgresql’), rule_files=[‘my_rules.py’], rule_dirs=[‘~/.sqltidy/rules’]

)

result = formatter.format(sql)
