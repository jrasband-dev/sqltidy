sqltidy.dialects.sqlite¶

SQLite dialect support.

This module provides SQLite-specific SQL dialect support including: - SQLite keywords - SQLite data types (simplified type system) - SQLite built-in functions - SQLite-specific features (PRAGMA, AUTOINCREMENT, etc.)

class sqltidy.dialects.sqlite.SQLiteDialect[source]¶

Bases: SQLDialect

SQLite database dialect.

property name: str¶

Unique identifier for this dialect (e.g., ‘sqlserver’, ‘postgresql’).

property keywords: Set[str]¶

SQLite keywords.

property data_types: Set[str]¶

SQLite data types.

SQLite uses a dynamic type system with type affinities: - INTEGER - TEXT - REAL - BLOB - NUMERIC

property functions: Set[str]¶

SQLite built-in functions.

property identifier_chars: str¶

SQLite doesn’t use special identifier characters.

property quote_chars: Dict[str, str]¶

SQLite quote characters for identifiers.

SQLite supports multiple quoting styles: - Double quotes: “identifier” - Backticks: identifier (MySQL compatibility) - Square brackets: [identifier] (SQL Server compatibility)

property comment_styles: List[str]¶

SQLite supports – and /* */ comments.

normalize_identifier(identifier)[source]¶

Normalize a SQLite identifier.

SQLite identifiers: - Case-insensitive by default (but preserved) - Can be quoted with “, `, or [] - Maximum length is unlimited (but practical limits apply)
