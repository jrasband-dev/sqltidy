class sqltidy.dialects.mysql.MySQLDialect[source]¶

Bases: SQLDialect

MySQL / MariaDB dialect.

Includes comprehensive MySQL keyword support with 280+ keywords covering: - DDL/DML operations - Query syntax - Data types (including MySQL-specific types) - Functions (string, date, aggregate, window, etc.) - MySQL-specific features (AUTO_INCREMENT, backticks, LIMIT syntax)

property name: str¶

Unique identifier for this dialect (e.g., ‘sqlserver’, ‘postgresql’).

property keywords: Set[str]¶

Comprehensive MySQL keywords.

property data_types: Set[str]¶

MySQL data types.

property functions: Set[str]¶

MySQL built-in functions.

property identifier_chars: str¶

MySQL doesn’t allow special chars in unquoted identifiers.

property quote_chars: dict¶

MySQL uses backticks for identifiers, single quotes for strings.

property comment_styles: list¶

MySQL supports –, # and /* */ comments.
