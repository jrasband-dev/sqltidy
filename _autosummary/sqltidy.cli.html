sqltidy.cli.resolve_rulebook_path(rulebook_ref)[source]¶

Resolve a rulebook reference to an actual file path.

Tries in order: 1. Exact path/filename (if exists) 2. Dialect name -> user rulebook if exists, otherwise bundled 3. Filename in user rulebooks, then bundled rulebooks

Parameters:

rulebook_ref (str) – Rulebook file reference (path, dialect name, or filename)

Returns:

Resolved path to rulebook file

Return type:

str

Raises:

FileNotFoundError – If rulebook cannot be found
